# 06. 레거시 — 쉘 스크립트 설치 자동화

> 공통 컨텍스트는 `00_마스터_PRD.md` 참조.
> ⚠️ PRD 05와 마찬가지로 날짜 미확정 — Kevin과 일정 재조정 후 진행.

## 1. 목표
PRD 01, 02, 05에서 **수동으로 진행했던 설치 과정**(httpd, Node.js, MySQL 5.7, Zabbix)을 쉘 스크립트로 재현 가능하게 자동화한다.

## 2. 배경/컨텍스트
착수보고서 "인프라 목표" 표에 "쉘 스크립트(Shell Script)로 레거시 서버 설치 과정 자동화"가 필수 항목으로 명시됨. 최신화의 Ansible과 대비되는 "레거시식 자동화" 사례로, 두 방식의 차이를 보여주는 포트폴리오 포인트가 된다.

## 3. 범위
- In-Scope: 웹서버 설치 스크립트, 앱서버(Node.js) 설치 스크립트, DB서버(MySQL 5.7) 설치 스크립트, Zabbix Agent 설치 스크립트
- Out-of-Scope: 애플리케이션 코드(CRUD 로직) 배포는 범위 밖 — 순수 "인프라 설치"만 자동화

## 4. 요구사항
1. 스크립트 저장 위치 결정 (예: `scripts/legacy/`)
2. `install_web.sh` — httpd 설치 + 기동 + 방화벽 개방을 순차적으로 실행하는 스크립트
3. `install_app.sh` — Node.js 모듈 활성화 + 설치 + 버전 확인
4. `install_db.sh` — MySQL 5.7 저장소 추가 + 설치 + 기동 + 방화벽 개방 (root 비밀번호 설정은 보안상 스크립트에 하드코딩하지 않고, 실행 시 입력받거나 별도 안내)
5. `install_zabbix_agent.sh` — Zabbix Agent 설치 + 설정파일(Server IP 등) 자동 치환 + 기동
6. **CLAUDE.md 규칙 준수**: 스크립트 안에서도 각 줄이 무엇을 하는지 주석으로 설명 (비전공자가 스크립트를 열어봐도 이해 가능하게)
7. 스크립트 실행 후 결과를 수동 설치했던 PRD 01/02/05의 완료 조건과 동일하게 재확인

## 5. 완료 조건 (DoD)
- [ ] 4개 스크립트 작성 완료
- [ ] 각 스크립트를 깨끗한 VM(또는 기존 VM 재실행)에서 1회 테스트 실행
- [ ] 수동 설치와 동일한 결과(서비스 active 상태) 확인
- [ ] `작업명령어_로그.md`에 스크립트 작성 및 테스트 과정 기록

## 6. 의존 관계

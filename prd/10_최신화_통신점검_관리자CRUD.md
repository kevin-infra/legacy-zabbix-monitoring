# 10. 최신화 — 3-Tier 통신 점검 + 관리자 CRUD(등록/대상고객선정)

> 공통 컨텍스트는 `00_마스터_PRD.md` 참조.

## 1. 목표
웹(nginx)→앱(FastAPI)→DB(MySQL 8.4) 3개 VM 간 통신을 최종 점검하고, 관리자(백오피스) 화면의 "기프티콘 등록"과 "대상 고객 선정" CRUD를 구현한다.

## 2. 배경/컨텍스트
착수보고서 일정상 10/14 작업. 착수보고서 3번 "백오피스" 항목: "관리자용 화면 구축 — 기프티콘 등록, 대상 고객 선정, 일괄 발급 트리거. 고객 화면에는 본인에게 증정된 건만 필터링되어 노출"

## 3. 범위
- In-Scope: 3-Tier 통신 점검, 관리자 기프티콘 등록 API+화면, 대상 고객 선정(목록 조회+다건 선택 UI) API+화면
- Out-of-Scope: 일괄 발급 실행 로직(→ PRD 11), 고객 조회 화면(→ PRD 11)

## 4. 요구사항
1. 통신 점검: 브라우저 → nginx → FastAPI → MySQL까지 전체 흐름 end-to-end 테스트 (`curl` 또는 브라우저로 `/health` 및 DB 조회 API 확인)
2. 관리자 인증/권한 구분 방식 결정 (간단한 수준: 별도 로그인 없이 `/admin` 경로로 구분할지, 최소 로그인 기능을 넣을지 — Kevin과 범위 확정 필요)
3. `POST /admin/coupons` : 기프티콘 등록 API (coupon_name, barcode, expiry_date 입력)
4. `GET /admin/users` : 전체 고객 목록 조회 API (대상 고객 선정 화면에서 사용)
5. 관리자 화면(최소 HTML/템플릿 또는 간단 프론트) 구성: 기프티콘 등록 폼, 고객 목록에서 체크박스로 다건 선택 UI
6. 선택된 고객 ID 목록을 다음 단계(PRD 11 일괄 발급)로 넘기는 방식 설계 (세션/임시 저장 또는 바로 발급 API에 포함해서 전달)

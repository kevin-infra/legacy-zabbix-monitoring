# 01. 레거시 — 웹서버(Apache) + 앱서버(Node.js) 설치

> 공통 컨텍스트는 `00_마스터_PRD.md` 참조. 환경: Rocky Linux 8, VM(gifticon-legacy-web), IP 192.168.56.10

## 1. 목표
레거시 VM에 웹서버(Apache)와 앱서버(Node.js 구버전)를 설치하고, 외부에서 접근 가능한 상태까지 만든다.

## 2. 배경/컨텍스트
착수보고서 일정상 10/7 작업. 3-Tier(웹-앱-DB) 중 웹·앱 계층을 먼저 세운다. DB서버는 PRD 02에서 별도 진행.

## 3. 범위
- In-Scope: httpd 설치/기동/방화벽 개방, Node.js(구버전) 설치/기동, 포트 확인
- Out-of-Scope: 앱 로직(CRUD)은 PRD 03에서, DB 연동은 PRD 02 이후

## 4. 요구사항
1. `dnf install httpd -y` 로 Apache 설치
2. `systemctl enable --now httpd` 로 자동시작 등록 + 기동
3. `systemctl status httpd` 로 `active (running)` 확인
4. `firewall-cmd --permanent --add-service=http` + `--reload` 로 80번 포트 개방
5. 호스트 브라우저에서 `http://192.168.56.10` 접속 테스트 (Apache 기본 페이지 확인)
6. Node.js(구버전, 예: 12.x~14.x 대 — 착수보고서 기준 "구버전"이라는 조건만 명시되어 있어 정확한 버전은 Kevin 확인 필요) 설치
   - `dnf module list nodejs` 로 사용 가능한 버전 스트림 확인
   - `dnf module enable nodejs:<버전>` 로 구버전 스트림 선택
   - `dnf install nodejs -y`
7. `node -v`, `npm -v` 로 설치 확인
8. 간단한 `Hello World` 수준의 Node.js 서버(포트 3000 등)를 띄워 앱서버 동작 확인 (본격 CRUD는 PRD 03)

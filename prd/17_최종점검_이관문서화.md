# 17. 최신화 — 전체 점검 + 이관 문서화 (최종)

> 공통 컨텍스트는 `00_마스터_PRD.md` 참조.

## 1. 목표
전체 플로우(웹→앱→DB)를 최종 재점검하고, 레거시→최신화 이관 과정을 문서화하며, 미완료 항목을 보완해 20일 일정을 마무리한다.

## 2. 배경/컨텍스트
착수보고서 일정상 10/25(재점검+문서화)~10/26(최종 점검, 팀 통합 준비). 발표자료(PPT)도 이 시점까지 분산 작성되어 있어야 함(착수보고서 7번 리스크 대응 — 마지막에 몰아서 만들지 않기).

## 3. 범위
- In-Scope: 전체 end-to-end 재점검, 이관 과정 문서화, 미완료 항목 정리, 발표자료 최종 정리, 팀 통합(Pod 배포) 준비
- Out-of-Scope: 팀 공통 쿠버네티스 클러스터 구성 자체 (팀 전체 작업)

## 4. 요구사항
1. PRD 01~16 전체의 완료 조건(DoD) 체크리스트를 다시 한 번 일괄 점검
2. 웹→앱→DB 전체 플로우 end-to-end 테스트 (관리자 등록→대상선정→일괄발급→고객조회→바코드사용→상태전환 전 과정)
3. 레거시→최신화 이관 과정 문서화 (별도 문서, 예: `docs/migration_summary.md`)
   - 레거시에서 어떤 문제가 있었는지 (PRD 04 증빙 자료 인용)
   - 최신화에서 어떻게 해결했는지 (PRD 13 트랜잭션, PRD 05 모니터링 등)
   - Before/After 비교표
4. 미완료 항목 정리 — 일정이 밀렸다면 착수보고서 7번 우선순위(VIP → k6 → CI/CD 순으로 제외)에 따라 범위 조정
5. 발표자료(PPT) 최종 취합 — 지금까지 분산 작성해둔 캡처/수치 자료를 하나로 정리
6. 팀 통합(쿠버네티스 Pod 배포) 대비 — Docker 이미지, 환경변수, 포트 등 팀에 전달할 정보 정리

## 5. 완료 조건 (DoD)
- [ ] 전체 end-to-end 플로우 재점검 통과
- [ ] 이관 문서화 완료

- [ ] 발표자료 최종본 완성
- [ ] 팀 통합용 정보 정리 완료
- [ ] `작업명령어_로그.md` 전체 내용 최종 검토 및 정리

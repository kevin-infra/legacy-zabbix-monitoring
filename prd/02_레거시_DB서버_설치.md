# 02. 레거시 — DB서버(MySQL 5.7) 설치 및 테이블 생성

> 공통 컨텍스트는 `00_마스터_PRD.md` 참조. 환경: Rocky Linux 8, 별도 DB용 VM 필요 (현재 1대뿐이면 추가 VM 생성부터)

## 1. 목표
레거시 DB서버에 MySQL 5.7을 설치·기동하고, `gifticon_users / gifticon_coupons / gifticon_transactions` 3개 테이블의 "간단 버전"을 생성한다.

## 2. 배경/컨텍스트
착수보고서 일정상 10/8 작업. 착수보고서 3번 "인프라 목표"에 "웹서버/앱서버/DB서버 각각 VM 3대로 분리 구축"이 명시되어 있으므로, 현재 VM이 1대뿐이라면 이 PRD 시작 전에 DB 전용 VM을 추가로 만들어야 함.

## 3. 범위
- In-Scope: DB VM 생성(필요시), MySQL 5.7 설치/기동, 방화벽 개방(3306), 테이블 3종 간단 버전 생성
- Out-of-Scope: 정식 제약조건(FK, 인덱스 등)은 최신화(PRD 09)에서 정식 설계

## 4. 요구사항
1. (필요시) Vagrantfile에 DB용 VM 블록 추가 — hostname `gifticon-legacy-db`, IP 예: 192.168.56.11
2. MySQL 5.7 저장소 설정 (Rocky 8 기본 저장소엔 MySQL 8 계열만 있을 수 있어 MySQL 공식 yum repo 추가 필요할 수 있음 — 설치 시점에 확인)
3. `dnf install mysql-community-server -y` (또는 해당하는 패키지명)
4. `systemctl enable --now mysqld`
5. `mysql_secure_installation` 으로 root 비밀번호 설정 및 보안 기본값 적용
6. 방화벽: `firewall-cmd --permanent --add-port=3306/tcp` + `--reload`
7. 데이터베이스 생성: `CREATE DATABASE gifticon_legacy;`
8. 테이블 3종 생성 (간단 버전, 컬럼 예시):
   ```sql
   CREATE TABLE gifticon_users (
     user_id INT AUTO_INCREMENT PRIMARY KEY,
     name VARCHAR(50),
     phone VARCHAR(20)
   );
   CREATE TABLE gifticon_coupons (
     coupon_id INT AUTO_INCREMENT PRIMARY KEY,
     coupon_name VARCHAR(100),
     barcode VARCHAR(50),
     status VARCHAR(20) DEFAULT '사용전'
   );
   CREATE TABLE gifticon_transactions (
     transaction_id INT AUTO_INCREMENT PRIMARY KEY,
     user_id INT,
     coupon_id INT,
     issued_at DATETIME,
     used_at DATETIME
   );
   ```
9. 웹/앱서버 VM에서 DB서버로 접속 테스트 (`mysql -h 192.168.56.11 -u ... -p`)
